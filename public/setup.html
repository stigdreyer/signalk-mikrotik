Set up MikroTik Data Meter

Four steps from installed to metering. Each one shows a tick when it's done.

  1. 1

    Internet state from signalk-internet

    The router switches to the allowlist when signalk-internet (Internet Connectivity Monitor) says the connection is metered. It's installed together with this plugin.

    Checking…

  2. 2

    Prepare the router

    Paste this script into the MikroTik's terminal (WinBox → New Terminal, or SSH). It turns on the secure REST API, creates a user for this plugin that can only log in from this Signal K server, sets the router's DNS options and sends connection data here. It's safe to run again.

    The router is already set up. This script keeps the plugin user's password, so running it again changes nothing that works. Press New password only if you want a new one: it goes into step 3 for you.

  3. 3

    Connect to the router

    Checks the router; changes nothing. Passing it ticks steps 2 and 3.

      Your plan, then start

      Optional. The billing day lines Data usage up with your provider's bill; the price lets the Allowlist estimate what allowing a service costs.

      Starting puts the plugin's firewall and DNS entries on the router, all marked signalk-mikrotik. They stay off until the connection is metered, and the plugin can remove them again.
